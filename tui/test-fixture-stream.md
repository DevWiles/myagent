Spring 的核心特性主要包括以下几个方面，它们共同构成了这个框架的基础能力。

1. IoC 控制反转：由容器负责对象的创建与依赖装配，显著降低组件之间的耦合程度。
2. DI 依赖注入：通过构造器或字段把协作对象交给使用方，让单元测试更容易编写。
3. AOP 面向切面：把日志、事务、权限这类横切关注点从业务代码里剥离出来。
4. 声明式事务：用注解描述事务边界，底层由代理和事务管理器负责具体的提交回滚。
5. MVC 模块：提供请求映射、参数绑定、视图解析的一整套 Web 层抽象。
6. 数据访问抽象：统一 JDBC、ORM 的异常体系与模板方法，屏蔽底层差异。
7. Boot 自动配置：按类路径上的依赖推断合理默认值，把样板配置降到最低。
8. 生态整合：与消息、缓存、安全、监控等组件有成熟的集成方案。

这些能力并不是彼此独立的，IoC 容器是其余一切的地基，AOP 依赖容器提供的代理机制，
而声明式事务又建立在 AOP 之上。理解这条依赖链，比单独记住每个特性更有价值。
